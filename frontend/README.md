# Task Tracker App

A full-stack task tracker application built using **MERN stack** (MongoDB, Express, React, Node.js) with user authentication, project/task management, and smooth animations using **Framer Motion**.

This app allows users to create tasks, update their status, and manage multiple projects effectively. The app includes a modern and intuitive UI with animations for smooth transitions.

---

## 🧩 Folder Structure

- `backend/`: Contains the Node.js and Express API to handle the business logic and data.
  - `controllers/`: Controller files for handling the API routes.
  - `models/`: MongoDB models to define the data structure.
  - `routes/`: Defines API routes to interact with the database.
  - `server.js`: Main file to start the backend server.
  - `.env`: Contains environment variables such as database URI and JWT secret.

- `frontend/`: Contains the React frontend.
  - `public/`: Public assets for the React application.
  - `src/`: Source code for the React components and application logic.
  - `package.json`: Dependencies for the React frontend.
